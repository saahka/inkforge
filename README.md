# InkForge — программа для цифрового рисования в браузере

Настольное веб-приложение для рисования: холст с масштабированием и панорамированием,
система слоёв, кисть с поддержкой графического планшета, сохранение проектов в IndexedDB.
Чистый JavaScript (ES-модули), без фреймворков и без сборки — Canvas2D + Pointer Events.

Это **Фаза 1** из плана (MVP): базовый холст, слои, кисть с давлением, сохранение.
Дальше — фазы 2–6 (см. раздел «Что дальше»).

---

## Запуск

ES-модули не работают через `file://` — нужен любой статический сервер.

**Вариант 1. Без установки зависимостей (Node.js 18+):**

```bat
cd paint
npm start
```

Откроется `http://localhost:5173/`.

**Вариант 2. Vite с горячей перезагрузкой:**

```bat
cd paint
npm install
npm run dev
```

**Вариант 3. Любой другой сервер** (в папке `paint`):

```bat
python -m http.server 5173
npx serve .
php -S localhost:5173
```

### Проверки кода

```bat
npm test           # 23 юнит-теста чистой логики (математика, цвет, заливка, блендинг, история)
npm run check      # статическая проверка, что все импорты разрешаются
npm run test:browser  # 30 сценариев в реальном Chrome через CDP: штрихи, слои, отмена, заливка
```

`test:browser` сам поднимает сервер и headless Chrome, проверяет реальные пиксели
холста (штрих лёг / не лёг, динамика давления, клиппинг выделения, композит слоёв)
и падает, если в консоли браузера появилась ошибка. Если Chrome/Edge не найдены —
тест молча пропускается.

## Что уже работает

### Холст
- масштабирование (Ctrl + колесо, кнопки `+ / − / ⤢`, Ctrl+0 — 100 %, Ctrl+1 — вписать);
- панорамирование (пробел + тяга, средняя кнопка мыши, обычное колесо);
- перерисовка только «грязной» области, отрисовка только видимой части слоёв;
- поддержка devicePixelRatio — линии на Retina не мылятся;
- прозрачность показывается «шахматкой», рамка документа рисуется в оверлее.

### Кисть
- Pointer Events: мышь, перо, палец — `pressure`, `tiltX/tiltY`, `pointerType`;
- `getCoalescedEvents()` — используются все точки кадра, а не одна (важно для 240 Гц пера);
- сглаживание: демпфирование координат + сплайн Catmull-Rom между точками;
- штрих рисуется в буфер и показывается мгновенно, в слой записывается один раз
  в конце — поэтому отклик не зависит от размера холста;
- предсказание траектории: экстраполяция последних точек рисуется «призраком»;
- параметры: размер, непрозрачность, поток, жёсткость, шаг, сглаживание;
- динамика от давления и наклона, зерно карандаша/акварели, кэш штампов;
- 11 пресетов кистей, превью с возможностью «протестировать мышью» прямо в панели.

### Слои
- создание, удаление, дублирование, переименование (двойной клик), объединение вниз,
  сплющивание, очистка, перетаскивание для сортировки;
- непрозрачность, 16 режимов наложения (12 — нативно Canvas2D, 4 — попиксельно
  по формулам W3C Compositing), блокировка, блокировка прозрачности;
- **clipping mask** — слой рисуется только внутри альфы слоя ниже;
- превью слоёв, меню слоя по правому клику, точки перетаскивания.

### Инструменты
| Клавиша | Инструмент |
|---|---|
| `B` | Кисть |
| `E` | Ластик (destination-out) |
| `G` | Заливка (допуск, учёт выделения и слоёв) |
| `⇧G` | Градиент (линейный/радиальный, Shift — угол 45°) |
| `I` | Пипетка (берёт цвет из итогового изображения; Alt по кисти — разовая пипетка) |
| `M` | Прямоугольное выделение |
| `V` | Перемещение содержимого (Ctrl — копия) |
| `H` / пробел | Панорамирование |

### Цвет
- цветовой круг (SV-плоскость + оттенок), HEX, RGB-слайдеры, HSL и CMYK;
- палитра (сохраняется в localStorage), недавние цвета, 6 цветовых гармоний;
- переключение основного/фонового цвета — `X`, сброс — `D`, непрозрачность цифрами `1…9`.

### Прочее
- история отмены/повтора с ограничением по шагам и по памяти, клик по шагу — перемотка;
- сохранение в IndexedDB (автосохранение раз в 2.5 с + `Ctrl+S`), галерея проектов;
- формат проекта `.inkforge.json` (File System Access API, с запасным скачиванием);
- экспорт PNG / JPEG / WebP с масштабом;
- drag & drop изображений в окно, импорт из буфера обмена (`Ctrl+V`);
- тёмная и светлая темы, режим фокуса (`F11`), скрытие панелей (`Tab`);
- счётчик памяти и истории — `F3`.

Панели справа идут в порядке **Инструмент → Слои → Цвет → История**; панели сворачиваются,
а док прокручивается целиком, поэтому на маленьком экране ничего не «схлопывается».
История по умолчанию свёрнута.

### Как устроен кадр

```
событие указателя
      │
      ▼
InputHandler ── coalesced точки ──▶ Tool (brush/eraser/…)
      │                                   │
      │                                   ▼
      │                            StrokeEngine
      │                       (сглаживание → Catmull-Rom → штампы в буфер)
      │                                   │
      │                                   ▼
      │                                Renderer ── экранный canvas (каждый кадр)
      │                                   │
      └──────────────────────────────►  Overlay (курсор, «муравьи», предсказание)
                                          │
                              конец штриха ▼
                          PixelCommand(«до»/«после» прямоугольника) → History
```

Ключевые решения:

- **Буфер штриха.** Штрих рисуется не в слой, а в отдельный canvas. В конце известна
  точная область изменений — достаточно сохранить `ImageData` только её, а не весь холст.
  Это делает историю лёгкой, а отклик — независимым от размера документа.
- **Dirty-rect.** Перерисовывается только изменившаяся область; для каждого слоя
  берётся пересечение с ней, поэтому 200 слоёв не удорожают кадр линейно.
- **Два canvas'а на экране.** Композит (`#viewCanvas`) и оверлей (`#overlayCanvas`).
  Оверлей не принимает событий — курсор кисти и «муравьи» не требуют перерисовки слоёв.
- **Один временный canvas на штрих** вместо аллокаций в каждом dab: GC не дёргает кадр.

## Ограничения Фазы 1 (что появится дальше)

| Сейчас | План |
|---|---|
| Холст до 8192×8192, буфер штриха до 4096² | Тайловый рендеринг 1024×1024 и целиком в WebGL |
| 12 кистев | Импорт `.abr` из Photoshop, текстуры-штампы, акварель и размазывание «по-настоящему» |
| Прямоугольное выделение | Лассо, «палочка», растушевка, инверт, расширение/сжатие |
| Нет фильтров | WebGL-шейдеры: яркость, уровни, кривые, размытие, резкость, художественные |
| Нет анимации | Покадровая анимация, onion skinning, экспорт в GIF/WebP-анимацию |
| Нет PSD | Чтение/запись PSD, экспорт SVG/PDF |
| Нет записи процесса | Запись штрихов, таймлапс, экспорт в видео |
| Нет групп слоёв | Группы, маски пользователя, adjustment-слои |
| Рендер на CPU (Canvas2D) | Перенос композитинга и фильтров на WebGL |

Прогресс по фазам: **Фаза 1 готова** → Фаза 2 (расширенные кисти, выделения, пипетка,
горячие клавиши — частично уже есть) → Фаза 3 (диалоги, темы, контекстные меню — есть)
→ Фаза 4 (WebGL и фильтры) → Фаза 5 (экспорт, вектор, градиенты) → Фаза 6 (анимация,
запись, облако, плагины).

## Заметки для разработчика

- Отладочный доступ: в консоли `INKFORGE.app`, `INKFORGE.input`, `INKFORGE.projectStore`.
- Тема: `localStorage['inkforge.theme']`, палитра — `inkforge.palette.v1`.
- Формат проекта: `{ format: 'inkforge/1', …, layers: [{ meta, data }] }`,
  `data` — PNG в base64. Читается в `js/utils/file.js:deserializeProject`.
- Чтобы добавить инструмент: создайте `js/tools/my-tool.js` с функцией-фабрикой,
  верните объект `{ id, cursor, label, settings, onPointerDown/Move/Up, drawOverlay }`
  и зарегистрируйте его в `core/app.js` → `#registerTools`.
- Чтобы добавить фильтр: реализуйте попиксельную функцию в `core/` и вызывайте её
  через `PixelCommand` — история и перерисовка подхватятся сами.
